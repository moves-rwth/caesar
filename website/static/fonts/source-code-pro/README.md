# Source Code Pro fonts

These unmodified WOFF2 files come from Adobe's official [source-code-pro release branch at commit `803b7e23ec97ae58b6232ea76519a76d428ba268`](https://github.com/adobe-fonts/source-code-pro/tree/803b7e23ec97ae58b6232ea76519a76d428ba268) (2025-10-28).
The upstream package version is 2.42.0.

The source files are `WOFF2/OTF/SourceCodePro-Regular.otf.woff2` and `WOFF2/OTF/SourceCodePro-It.otf.woff2`.
Source Code Pro includes Regular (400), with matching italics, for code blocks.
The files retain upstream glyph coverage and have not been subsetted or converted.
