# IBM Plex Sans fonts

These unmodified, complete WOFF2 files come from [IBM/plex commit `763c36ef9117782905ae010056dfbe8fd2653a25`](https://github.com/IBM/plex/tree/763c36ef9117782905ae010056dfbe8fd2653a25) (2026-09-22).
IBM Plex Sans is version 1.1.0.

The source directory is `packages/plex-sans/fonts/complete/woff2/`.
IBM Plex Sans includes SemiBold (600) and Bold (700), with matching italics, for headings.
The files retain the upstream complete fonts' glyph coverage and have not been subsetted or converted.

The fonts are distributed under the SIL Open Font License 1.1 in [LICENSE.txt](LICENSE.txt), copied unchanged from `packages/plex-sans/LICENSE.txt` at the same commit.
