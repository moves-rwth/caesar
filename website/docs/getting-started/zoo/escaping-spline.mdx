## The Program

The procedure starts at the nonnegative integer `init_x` and repeats this step while `x` is positive.

```heyvl title="Unannotated HeyVL program"
proc escaping_spline(init_x: UInt) -> (x: UInt) {
    x = init_x
    while x > 0 {
        var stop: Bool = flip(1 / (x + 1))
        if stop {
            x = 0
        } else {
            x = x + 1
        }
    }
}
```

If `init_x` is zero, the loop performs no iterations.

## Verification {#almost-sure-termination}

With the [`@wp` annotation](../../heyvl/procs.md) and postexpectation `1`, the weakest preexpectation is the termination probability.
Caesar verifies `pre 1`, establishing almost-sure termination (termination with probability one) for every `init_x`.

The [`@ast` annotation](../../proof-rules/ast.md) uses variant `x`:

For the highlighted annotation, Caesar checks:

- **Progress:** for positive integer `x`, the jump to zero decreases the variant by at least one with probability `1/(x+1)`.
- **Expected variant:** one iteration does not increase its expected value:

  $$
  \frac{1}{x+1}\cdot 0+\frac{x}{x+1}\cdot(x+1)=x.
  $$

The functions `1/(v+1)` and `1` are positive and nonincreasing for $v\ge0$, with `1/(v+1) <= 1`.

## Expected Number of Iterations {#stopping-probability-and-waiting-time}

Almost-sure termination alone does not imply a finite expected number of iterations.
For this loop, the separate calculation below shows that the expected number is infinite whenever the initial value is positive.

Starting at $m>0$, let $T$ count the loop iterations.
Executing more than $n$ iterations requires $n$ consecutive increments:

$$
\Pr(T>n)=\prod_{k=0}^{n-1}\frac{m+k}{m+k+1}=\frac{m}{m+n}
\qquad(n\ge 0).
$$

Summing these probabilities gives the expected number of iterations:

$$
\mathbb{E}[T]=\sum_{n=0}^{\infty}\Pr(T>n)
=\sum_{n=0}^{\infty}\frac{m}{m+n}=\infty.
$$

The harmonic series diverges, so the loop is not [positively almost-surely terminating](../../proof-rules/past.md) for $m>0$.
